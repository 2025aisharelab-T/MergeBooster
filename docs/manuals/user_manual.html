제1장. 프로그램 개요 및 도입 효과

Excel Diff Aggregator는 여러 부서나 사용자가 동일한 엑셀 서식을 바탕으로 입력/수정한 다수의 수정본 엑셀 문서(`.xlsx`)에서 변경된 셀 데이터만 자동으로 추출하여 1개의 원본(Base) 문서에 덮어쓰고 visual 하이라이트를 적용해 주는 C# 기반 전용 데스크톱 솔루션입니다.

기존 수동 취합과의 비교

구분 기존 수동 복사/붙여넣기 방식 Excel Diff Aggregator 방식
필터/숨겨진 행 Handling 필터나 숨겨진 행이 있을 경우 행 덮어쓰기 오작동 발생 위험 높음 2차원 메모리 배열 (Row, Col) 1:1 정밀 비교로 100% 위치 보장
다중 파일 처리 수정본이 10개면 10번 수동으로 열어 확인 후 복사해야 함 수정본 파일 일괄 추가 후 클릭 한 번으로 연속 취합
변경 이력 관리 어떤 셀이 수정되었는지 일일이 색상을 칠하거나 메모 남겨야 함 연한 노란색 배경 음영 + 기존 값 메모(주석) 자동 기록
제2장. 시스템 요구사항 및 실행 안내

본 프로그램은 추가적인 설치 과정(Installer)이 필요 없는 단일 독립 실행 파일(`MergeBooster.exe`) 형태로 제공됩니다.

실행 환경 사양

  • 운영체제(OS): Microsoft Windows 7 / 10 / 11 (32bit / 64bit)
  • 필수 프레임워크: Microsoft .NET Framework 4.0 이상
  • 엑셀 소프트웨어: Microsoft Excel 2010 이상 설치 권장
  • 실행 파일: MergeBooster.exe (단일 Executable)
📌 실행 팁: MergeBooster.exe 파일 하나만 원하는 폴더에 복사해 두고 바로 더블 클릭하여 실행할 수 있습니다.
제3장. 사용자 인터페이스 (GUI) 구조

프로그램 실행 시 직관적이고 친근한 Soft Modern Card UI 화면이 표시됩니다.

메인 화면 주요 구역

구역 명칭 컨트롤 요소 기능 및 설명
1. 원본 파일 설정 txtBasePath, [원본 파일 선택] 취합 기준이 될 기준(Base) 엑셀 파일 지정 (.xlsx)
2. 수정본 파일 목록 lstModFiles, [➕ 파일 추가] 등 변경사항이 담긴 1개 이상의 수정본(.xlsx) 목록 추가/삭제
3. 옵션 패널 비교 시트명, 체크박스 2종 시트 자동 인식 모드 지정, 노란색 하이라이트 및 주석 기록 설정
4. 실행 버튼 영역 [🚀 취합 실행], [🧹 메모&음영 제거] 변경사항 병합 실행 및 결과물 서식 초기화 수행
5. 콘솔 상태 로그 txtLog (Slate Black Console) 진행 단계, 셀 변경 개수, 성공/실패 여부를 실시간 출력
[17:05:00] 🚀 취합 작업 시작... [17:05:01] 📄 Base: d:\project\test\input\base.xlsx [17:05:01] 🔍 [전체 시트 자동 인식 모드] 작동 중... [17:05:02] - Sheet '영업1팀': 12개 셀 업데이트 완료! [17:05:03] ✅ 취합 성공! 총 12개 변경사항이 병합되었습니다.
제4장. 단계별 상세 사용법 및 시나리오

기본 취합 진행 단계 (Step-by-Step)

  1. Step 1. 원본 파일 선택: 상단의 [원본 파일 선택] 버튼을 눌러 최종 결과물로 작성될 기준 엑셀 파일 선택.
  2. Step 2. 수정본 파일 추가: [➕ 파일 추가] 버튼을 클릭하여 각 부서/담당자가 제출한 엑셀 파일들 선택 (다중 선택 가능).
  3. Step 3. 시트 옵션 확인: 비교 시트명란이 (전체 시트 자동 인식)으로 되어 있는지 확인. (필요 시 특정 시트명 입력 가능)
  4. Step 4. 취합 실행: [🚀 변경사항 취합 실행] 버튼 클릭. 별도 백그라운드 스레드에서 정밀 비교 후 자동 저장.
  5. Step 5. 결과 확인: 원본 파일 열기. 변경된 셀이 연한 노란색(RGB 255, 242, 204)으로 표시되고 마우스를 올리면 이전 데이터가 메모로 표시됨.
⚠️ 주의사항: 원본 파일 및 수정본 파일이 엑셀 프로그램(Microsoft Excel)에서 열려 있는 경우, 파일 잠금(Lock) 현상으로 인해 취합 과정에서 에러가 발생할 수 있습니다. 취합 전 엑셀 창을 모두 닫아주세요.
제5장. 특수 기능 (음영/메모 제거) 및 FAQ

🧹 메모 & 음영 선택적 제거 기능

취합 검토 완료 후 보고서 제출 등을 위해 취합용 강조 효과만 선택적으로 제거할 때 활용합니다.

  • 안전한 선택적 제거 방식: 원본 파일 선택 후 [🧹 메모&음영 제거] 버튼을 클릭하면, 취합 과정에서 생성된 노란색 하이라이트(RGB 255, 242, 204) 및 이전 값 주석([기존 값:])만 탐지하여 정밀 제거합니다.
  • 원본 서식 및 메모 보존: 원본 엑셀 문서가 원래 가지고 있던 배경 서식(헤더 색상, 데이터 구분 색상 등)과 사용자가 직접 작성했던 기존 메모는 전혀 영향을 받지 않고 안전하게 보존됩니다.

자주 묻는 질문 (FAQ)

Q1. 수정본 파일에 특정 시트가 없으면 어떻게 되나요?
A. 전체 시트 자동 인식 모드에서는 원본 시트 기준으로 동작하며, 수정본에 동명의 시트가 없으면 해당 시트는 안전하게 스킵(Skip)하고 다음 시트를 비교합니다.

Q2. 필터가 걸려있는 상태에서 취합을 진행해도 괜찮나요?
A. 네! 본 프로그램은 엑셀 화면 표시 상태와 무관하게 2차원 메모리 데이터 배열 기준으로 비교하므로 필터나 숨겨진 행이 있어도 100% 정확하게 일치하는 셀에 반영됩니다.
