엑셀 변경사항 자동 취합기 - Quick Start Guide

필터 및 숨겨진 행에 상관없이 수정본 변경 셀만 1:1로 정밀 취합하는 스마트 도구

Quick Guide (A4 1P)
3단계 초간단 사용 방법
STEP 1

엑셀 파일 등록

[원본 파일 선택] 버튼으로 기준 엑셀 등록 후, [➕ 파일 추가]로 여러 수정본(.xlsx)을 목록에 등록합니다.

STEP 2

옵션 및 시트 확인

시트명 기본값 (전체 시트 자동 인식)을 유지하거나 특정 시트 지정 후 노란색 음영/주석 기록 옵션을 확인합니다.

STEP 3

취합 실행 및 확인

[🚀 변경사항 취합 실행] 클릭! 콘솔 로그에서 완료 메시지를 확인하고 결과 원본을 엽니다.

주요 핵심 기능 요약
📁

다중 수정본 일괄 병합

수정본 파일 여러 개를 순차적으로 1개의 원본 파일에 오차 없이 병합 및 덮어쓰기합니다.

🔄

전체 시트 자동 인식

시트명을 일일이 입력하지 않아도 원본 문서의 모든 워크시트를 자동 감지하여 교차 취합합니다.

⚡

1:1 메모리 배열 비교

2차원 배열 로딩으로 속도가 매우 빠르며, 필터/숨겨진 행에 구애받지 않고 셀 절대좌표 비교를 수행합니다.

🧹

메모 & 음영 선택적 제거

[🧹 메모&음영 제거] 버튼 클릭 시, 취합 중 생성된 노란색 배경(#FFF2CC)과 이전 값 주석만 선택 삭제되며 원본 서식/메모는 완벽 보존됩니다.

주요 기능 버튼 안내
버튼 명칭 색상 테마 기능 설명
🚀 변경사항 취합 실행 Indigo / Blue 선택한 모든 수정본의 변경 셀을 원본 엑셀에 최종 반영하고 하이라이트/주석 처리.
🧹 메모 & 음영 제거 Purple / Amber 취합 중 반영된 노란색 하이라이트 및 [기존 값:] 주석만 선택적으로 깨끗이 제거 (원본 고유 서식/메모 보존).
➕ 파일 추가 Emerald Green 취합할 수정본(.xlsx) 엑셀 파일들을 탐색기 대화상자에서 여러 개 동시에 추가.
💡
실무 꿀팁: 원본 파일과 수정본 파일이 엑셀 실행 중에 열려있으면 파일 접근 권한 오류가 발생할 수 있습니다. 취합 실행 전 엑셀 창을 모두 닫아주세요.
