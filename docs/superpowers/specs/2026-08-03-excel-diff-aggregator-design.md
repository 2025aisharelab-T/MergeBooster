# 엑셀 변경사항 자동 취합기 (Excel Diff Aggregator) 설계서

- **작성일**: 2026-08-03
- **형식**: VBA 매크로가 내장된 엑셀 파일 (`ExcelDiffAggregator.xlsm`)
- **목적**: 필터 및 숨겨진 행(Hidden Rows)으로 인한 복사/붙여넣기 오류를 방지하고, 원본 문서 대비 수정본 문서의 변경된 셀만 추출하여 원본에 자동 덮어쓰기 및 하이라이트(노란색) 적용.

---

## 1. 시스템 구조 및 사용자 인터페이스

### 1.1 `[대시보드]` 시트 구성
취합기 파일(`ExcelDiffAggregator.xlsm`)의 메인 시트입니다.

| 영역 | 구성 요소 | 설명 |
| :--- | :--- | :--- |
| **파일 선택** | `원본 파일 선택` 버튼 | 기준이 되는 원본 `.xlsx` 경로 지정 |
| | `수정본 파일 선택` 버튼 | 변경사항이 포함된 수정본 `.xlsx` 경로 지정 |
| **설정 옵션** | 비교 시트명 (기본값: `첫번째 시트`) | 특정 시트 지정 가능 |
| | 하이라이트 색상 (기본값: `#FFF2CC`) | 연한 노란색 RGB(255, 242, 204) |
| | 이전 값 주석(셀 메모) 기록 여부 | `예` / `아니오` 선택 |
| | 취합 결과 파일 자동 저장 여부 | `예` / `아니오` 선택 (저장 위치: 원본 동일 폴더) |
| **실행 제어** | `취합 및 하이라이트 실행` 버튼 | 메인 VBA 매크로 실행 |
| | `하이라이트 색상 초기화` 버튼 | 취합 결과물의 강조 색상 제거 |

## 2. 핵심 VBA 알고리즘 및 모듈 설계

### 2.1 주요 모듈 구성
1. `mod_Main`: 취합 프로세스 전체 흐름 제어 및 이벤트 처리
2. `mod_DiffEngine`: 원본 및 수정본 데이터 메모리 배열 비교, 변경 셀 덮어쓰기, 하이라이트 및 메모 기록
3. `mod_FileDialog`: Excel `FileDialog` API 기반 파일 선택 래퍼 함수
4. `mod_Utils`: 화면 갱신 차단(`ScreenUpdating`), 자동 계산 일시 정지(`Calculation`), 안전한 에러 핸들링

### 2.2 메커니즘 상세
- **메모리(배열) 1:1 비교**:
  - `OriginalRange.Value` 및 `ModifiedRange.Value`를 `Variant` 2차원 배열로 로드하여 초고속 비교.
  - 필터나 숨겨진 행 여부와 관계없이 절대 좌표 `Array(Row, Col)` 기반으로 정확히 1:1 비교.
- **변경 판정 및 반영 조건**:
  - `Modified(r, c) <> Original(r, c)` 이고 `Modified(r, c) <> ""` 인 경우.
  - 원본 워크시트의 셀 `Cells(r, c).Value = Modified(r, c)`로 업데이트.
  - 해당 셀 `Interior.Color = RGB(255, 242, 204)` 하이라이트 설정.
  - 주석 옵션이 `예`인 경우 셀 `AddComment` 처리 (`기존 값: [Original(r, c)]`).

## 3. 검증 및 예외 처리 계획

1. **파일/시트 존재 여부 검증**: 선택한 원본 및 수정본 파일이 올바른 엑셀 파일인지 및 비교 대상 시트가 존재하는지 확인.
2. **범위 불일치 처리**: 원본과 수정본의 사용된 영역(`UsedRange`) 크기가 다를 경우, 교집합 영역 탐지 및 크기 자동 조정.
3. **화면 및 계산 속도 최적화**: 매크로 시작 시 `Application.ScreenUpdating = False`, `Application.Calculation = xlCalculationManual` 처리 후 종료 시 복구.
